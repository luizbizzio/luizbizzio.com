# Security Policy

## Supported version

Only the current version of [luizbizzio.com](https://luizbizzio.com/) is maintained.

Old deployments, copies, and forks are not supported by this policy. Each project linked from the portfolio has its own security and support process.

## Reporting a vulnerability

Please report security problems privately. **Do not open a public issue or post exploit details before we have discussed a fix.**

Send a report to **contact@luizbizzio.com** with the subject **Security report: luizbizzio.com**.

Include:
- A short description of the problem and its possible impact.
- The affected page, feature, or file.
- Clear steps to reproduce the issue.
- A small proof of concept, if needed.
- A way to contact you if more information is required.

Do not include passwords, access tokens, personal data, or any secrets that you do not own.

Reports are reviewed on a best-effort basis. A response time or a reward is not guaranteed.

## Safe testing

Please avoid actions that could affect the site or other people, including:
- Denial-of-service tests, heavy scanning, or large automated requests.
- Social engineering, phishing, or attacks on users.
- Accessing, modifying, or sharing data that is not yours.
- Attacking hosting providers or other third-party services.

Use the minimum testing needed to explain a problem, then stop and report it.

## Disclosure

Please allow time to investigate and fix a confirmed issue before sharing its details publicly. Credit may be given if requested and agreed in advance.

## Scope

This policy covers the portfolio website itself, not the independent projects listed in it. Report problems in a linked project to that project's own maintainer or security channel.
